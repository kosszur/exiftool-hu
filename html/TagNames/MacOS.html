MacOS tagek

MacOS rendszereken további MDItem és XAttr Finder tagek nyerhetők ki. Ezek a tagek alapértelmezés szerint nem kerülnek kinyerésre – kifejezetten kérni kell őket, vagy egy API-opcióval engedélyezni. (Kivéve, amikor közvetlenül a MacOS "._" fájlokat olvassuk, lásd lentebb.)

Az alábbi táblázatok a kinyerhető tagek egy részét sorolják fel, de az ExifTool minden elérhető információt kinyer, még a nem listázott tagek esetében is.

Az ezekben a táblázatokban lévő tageket "pszeudo" tageknek nevezzük, mert az információjuk nem magában a fájlban tárolódik. Ezért az ezekben a táblázatokban Writable (írható) tagek a fájl újraírása nélkül módosíthatók.

Vegyük figyelembe, hogy egyes fájlrendszereken a MacOS "._" kezdetű nevű kísérőfájlokat hoz létre. Az ExifTool megadás esetén beolvassa ezeket a fájlokat, és extra opciók nélkül kinyeri a következő táblázatban felsorolt információkat, de ezek a fájlok közvetlenül nem írhatók.

MacOS XAttr tagek

Az XAttr tageket az "xattr" segédprogrammal nyerjük ki. Akkor kerülnek kinyerésre, ha kifejezetten kérünk valamely "XAttr*" taget vagy a MacOS csoportot, vagy ha az API XAttrTags opcióját 1-re, illetve az API RequestAll opcióját 2-re vagy magasabbra állítjuk. A MacOS "._" fájlokból pedig alapértelmezés szerint kinyerésre kerülnek, amikor ezeket a fájlokat közvetlenül olvassuk.
